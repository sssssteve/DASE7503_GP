# 官方尺寸候选图

围墙按课程《QR Code and Game Field》第 2 页的尺寸图生成。假设场地内壁相距 3.02 × 2.00 m，需现场复测。分辨率 0.02 m。地图只写入固定围墙，保留外围未知格。可移动的货架由实时雷达和代价地图处理。

坐标以尺寸图为准。目的区在左，START 在右。左下内角为 (0, 0)，x 向右指向 START，y 向上。START 区的范围是 x=2.42–3.02 m、y=0.60–1.40 m。目的区是 x=0–0.80 m、y=0.30–1.70 m。地图 YAML 的负原点用于在墙外留边。

复制实车配置后填入这张地图与起始区，先校准实际雷达安装角。以下地图路径相对于放在 `pi_hardware/` 下的配置：

```yaml
map: ../pi_ws/maps/official_reference/field.yaml
start_region: [2.42, 0.60, 3.02, 1.40]
initial_pose: null
```

预靠点和放置点也要统一换算到上面的坐标系。启动比赛定位前退出在线 SLAM，使用 `pi.sh nav` 和 `pi.sh check`。车在 START 区内静止，确认定位通过并核对两面固定墙是否与雷达重合后，再考虑运行比赛。若围板缺少稳定回波、定位多解或场地尺寸不一致，应先修正实际条件。
